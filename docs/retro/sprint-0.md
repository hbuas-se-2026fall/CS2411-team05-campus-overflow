## 1. 匿名卡片汇总（每位成员贴 3 张，本栏匿名归并）

### ✅ Start（开始做 —— 值得尝试的新做法）
1. 从个人仓库切换到教师指定的组织共享仓库，统一"分支 + PR + CI"协作流程，避免 fork 模型的信息孤岛。
2. 为 develop / main 配置分支保护（develop≥1 Approve、main≥2 含 SM/PO），用规则约束而非自觉。
3. 建立 Projects 看板与 Sprint Milestone，让任务状态对全员可见。

### 🛑 Stop（停止做 —— 阻碍/低效的做法）
1. 不再沿用 `lab6(tN):` 之类非标准提交前缀，统一使用 Conventional Commits（feat/fix/docs（scope））。
2. 不要再出现 git 身份未统一（双 @ 邮箱笔误、多人共用邮箱）导致 GitHub 无法认领贡献。
3. 不要等 Sprint 末尾才集中合并 PR，评审应随开发进行。

### 🔄 Continue（继续做 —— 行之有效的做法）
1. 保持按 Sprint Goal 拆分 PBI 与验收标准，用验收用例驱动开发。
2. 坚持用访谈提炼需求（docs/backlog/interviews），让产品决策有据可依。
3. 保持文档同步沉淀（backlog / ADR / 契约）。
